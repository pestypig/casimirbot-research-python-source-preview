# Research Python source: combined private review draft

This unlicensed, private source-only draft pins 359 exact `docs/research/` Python paths to `SOURCE_SELECTION.json`: the 345-file filtered selection plus 14 files recovered from a false-positive email-pattern hold. The two original inventories are retained as `SOURCE_SELECTION_345.json` and `SOURCE_SELECTION_14.json`. Ten separate QCDark2, WIMpy, and nuflux archives are excluded because their bytes and licenses belong to their upstream projects. This draft is not a public release, runnable research package, accepted dataset, proof, certificate, physical-viability result, or reproduced scientific conclusion. External papers, datasets, and dependencies are not bundled. Do not execute these scripts against services or unpublished observations from this draft.

The [dependency and upstream-reference review](DEPENDENCIES_AND_REFERENCES.md) identifies selected imports, citation URLs, and a pinned WIMpy fetch/execute path. The 14 additional files import NumPy, SciPy, `wilson`, and h5py and refer to neighboring scripts and JSON/HDF5 inputs that are absent here. Exact owner MIT rights for both selections, copied-content and data review, final notices, and an exact Public exposure decision remain open. No fetched upstream source is bundled in this draft.
